Fichier autonome, sans backend. Les champs relatifs au statut vaccinal individuel et aux ressources logistiques n'étant pas renseignés dans la base source, les blocs correspondants affichent des estimations clairement signalées plutôt que des données mesurées.

Synchronisation en direct — Ce fichier peut se mettre à jour automatiquement depuis un Google Sheet public (onglet « KWAIDS OK complet » publié au format CSV). Pour l'activer : ouvrez ce fichier .html dans un éditeur de texte, repérez la ligne csvUrl: 'PASTE_YOUR_PUBLISHED_CSV_URL_HERE' près du bas du fichier, et remplacez-la par l'URL générée via Google Sheets → Fichier → Partager → Publier sur le web → onglet « KWAIDS OK complet » → format CSV. Tant qu'aucune URL n'est renseignée, le tableau de bord reste pleinement fonctionnel avec les données chargées lors de sa création.
